# MiniStore

MiniStore is an e-commerce application designed for managing and selling skincare and sun protection products online. It provides a user-friendly interface for browsing products, managing inventory, and processing orders.

## Features

- Product Catalog: Display a grid of products with images, names, and prices.
- Product Categories: Organize products into various categories for easy navigation.
- Search Functionality: Allow users to search for specific products using the search bar.
- Inventory Management: Add, edit, and remove products from the store's inventory.
- Order Processing: Handle the process of placing and managing customer orders.

## Technologies Used

- Frontend:
  - HTML5
  - CSS3
  - JavaScript
 

- Backend:
  - Static site



## Getting Started

1. Clone the repository:
   ```
   git clone https://github.com/your-username/ministore.git
   ```

2. Install the dependencies:
   ```
   cd ministore
   npm install
   ```


4. Start the development server:
   ```
   npm start
   ```

5. Open your browser and navigate to `http://localhost:3000` to access the application.
